Un solo instalador

Windows 10/11 x64 con .NET Framework 4.8. English y Español. Incluye el plugin SCS para Euro Truck Simulator 2 y American Truck Simulator. Este instalador de versión preliminar no tiene firma digital; Windows puede mostrar un aviso de editor desconocido. Descarga solo desde esta página y verifica el SHA-256. No desactives protecciones de seguridad para instalarlo.

1. Instala y elige el juego

Ejecuta el instalador como tu usuario de Windows. Abre TADEX Connect y elige el juego. Detecta carpetas habituales de Steam y Epic; selecciona la carpeta del juego si hace falta.

2. Prepara el juego

ETS2 / ATS: cierra el juego, pulsa Preparar juego y acepta su aviso de telemetría SDK al volver a abrirlo. DiRT Rally 2.0 / EA SPORTS WRC: abre y cierra el juego una vez y usa Preparar juego. Connect respalda los archivos antes de cambiarlos. AC, ACC e iRacing usan su SDK integrado. En AMS2 elige System → Shared Memory → Project CARS 2. Para GT7 introduce la IP de PlayStation y la interfaz de red del PC; consola, PC y teléfono deben estar en la misma red.

3. Enlaza el teléfono

Empieza una sesión real en TADEX en el teléfono. En Conexión, copia el enlace de TADEX Connect y pégalo en Connect del PC, o introduce la IPv4 local del teléfono y el puerto UDP. Pulsa Iniciar conexión y empieza a conducir. Mantén ambas aplicaciones activas.

Componente de Microsoft, solo si falta

El plugin SCS necesita Microsoft Visual C++ v14 x64. La mayoría de los PC de juegos ya lo tienen. Si falta, Connect ofrece la descarga oficial de Microsoft y abre su instalador, que puede pedir permisos de administrador. Ese paso opcional necesita Internet. El componente de Microsoft no se redistribuye dentro del instalador TADEX.

Tú controlas los cambios

Sin servicios de Windows, inicio automático ni cambios al firewall. Preparar puede pedir permisos para carpetas protegidas. Restaurar configuración anterior revierte los cambios propios de Connect cuando los archivos no se editaron después. Se conservan los archivos modificados. Desinstala desde Aplicaciones instaladas de Windows; las preferencias personales se conservan. Respalda configuraciones importantes antes de preparar.

Conexiones incluidas

ETS2, ATS, Assetto Corsa, Assetto Corsa Competizione, iRacing, Automobilista 2 y GT7 necesitan Connect. DiRT Rally 2.0 y EA SPORTS WRC pueden usar su preparación automática o UDP directo. Forza Horizon 5, Forza Motorsport, Forza Horizon 6, F1 24, F1 25 y BeamNG.drive usan UDP directo compatible y no necesitan este complemento. La disponibilidad depende de la edición, plataforma y configuración del juego.
