One installer

Windows 10/11 x64 with .NET Framework 4.8. English and Español. Includes the SCS telemetry plugin for Euro Truck Simulator 2 and American Truck Simulator. This preview installer is not digitally signed; Windows may display an unknown-publisher warning. Download only from this page and check the SHA-256. Do not disable security protection to install it.

1. Install and choose your game

Run the installer as your Windows user. Open TADEX Connect and select the game. Common Steam and Epic folders are detected; select your game folder if needed.

2. Prepare the game

ETS2 / ATS: close the game, click Prepare game, and accept the game’s SDK telemetry prompt on next launch. DiRT Rally 2.0 / EA SPORTS WRC: open and close the game once, then use Prepare game. Connect backs up files before changing them. AC, ACC and iRacing use their built-in SDK. In AMS2 choose System → Shared Memory → Project CARS 2. For GT7, enter your PlayStation IP and the PC network interface; keep the console, PC and phone on the same network.

3. Link your phone

Start a live session in TADEX on the phone. In Connection, copy the TADEX Connect link and paste it into Connect on the PC, or enter the phone’s local IPv4 address and UDP port. Click Start connection and start driving. Keep both applications active.

Microsoft runtime, only if needed

The SCS plugin needs Microsoft Visual C++ v14 x64. Most gaming PCs already have it. If missing, Connect offers the official Microsoft download and opens Microsoft’s installer, which may request administrator approval. That optional step needs Internet. The Microsoft runtime is not redistributed in the TADEX installer.

Changes you control

No Windows service, automatic startup or firewall changes. Preparation may ask permission for protected game folders. Restore previous setup in Settings reverses Connect’s own changes when the files have not since been edited. Modified files are preserved. Uninstall through Windows Installed apps; personal settings are kept. Back up important game settings before preparation.

Included connections

ETS2, ATS, Assetto Corsa, Assetto Corsa Competizione, iRacing, Automobilista 2 and GT7 need Connect. DiRT Rally 2.0 and EA SPORTS WRC can use its automatic setup or direct UDP. Forza Horizon 5, Forza Motorsport, Forza Horizon 6, F1 24, F1 25 and BeamNG.drive use supported direct UDP and do not need this companion. Telemetry availability depends on the game edition, platform and settings.
